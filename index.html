📊 Statistik & Pencarian Wilayah — DATA LENGKAP

38 Provinsi · 514 Kab/Kota · 7.285 Kecamatan · 83.762 Desa/Kelurahan — kode Kemendagri (Kepmendagri 300.2.2-2138/2025), dimuat langsung dari API statis wilayah Indonesia (update data 11 Okt 2026). Angka ini beda dari klaim BIG RBI di situs acuan karena beda sumber: ini kode administrasi Kemendagri, bukan hitungan geometri RBI.

👥 Indikator Wilayah Terpilih

Pilih wilayah di atas — ibu kota, penduduk, luas, elevasi, zona waktu, dan kode pos (desa) tampil di sini dari data API yang sama.

🛰 Citra Satelit & Radar — BMKG

Citra geostasioner resmi BMKG (sumber: satellite.bmkg.go.id) & radar cuaca nasional (gis.bmkg.go.id). Pilih produk, geser waktu, atau putar animasinya.

🌐 GeoPortal Hub — SatuPeta BIG

Basemap Rupabumi BIG tersedia di pemilih layer peta (kanan atas). Layer WMS/WFS/ArcGIS publik bisa dimuat lewat GEOTOOLS → ArcGIS REST.

🏔 Unduh DEMNAS (konsep)

Alur aslinya: pilih indeks DEMNAS → clip batas wilayah → unduh GeoTIFF tanpa token dari BIG. Di prototype ini gunakan Export di GEOTOOLS untuk GeoJSON hasil gambar.
